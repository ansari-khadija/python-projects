🧮 Python Function-Based Calculator

A simple, interactive calculator built with Python that performs basic arithmetic operations using user-defined functions. This beginner-friendly project demonstrates how functions make code reusable, organized, and easy to maintain.

✨ Features
➕ Addition — Adds two numbers.
➖ Subtraction — Subtracts one number from another.
✖️ Multiplication — Multiplies two numbers.
➗ Division — Divides two numbers with zero-division protection.
✅ Input Validation — Handles invalid numeric inputs.
🔄 Function-Based Design — Uses separate functions for each arithmetic operation.
🖥️ Interactive Interface — Accepts user input through the terminal.
🛠️ Technologies Used
Language: Python 3
Concepts: Functions, parameters, return values, conditional statements, exception handling, and user input.
🚀 Getting Started
Prerequisites

Install Python 3 from the official website:

https://www.python.org/downloads/

Installation
Clone this repository:
   git clone https://github.com/ansari-khadija/python-function-calculator.git

Navigate to the project directory:
   cd python-function-calculator

Run the program:
   python main.py


If needed, use python3 main.py instead.
