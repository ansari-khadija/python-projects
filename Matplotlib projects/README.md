📊 E-Commerce Sales Analysis Dashboard

A professional E-Commerce Sales Analytics Dashboard built using Python, Pandas, Matplotlib, and Seaborn. This project transforms raw sales data into meaningful business insights through clean and interactive-looking visualizations.

🚀 Project Overview

The main objective of this project is to analyse e-commerce sales performance, understand customer behaviour, evaluate product categories, and identify regional sales trends.

The dashboard combines multiple visualizations into a single professional report.

🛠️ Technologies Used
Python
Pandas – Data manipulation and analysis
NumPy – Numerical operations
Matplotlib – Data visualization
Seaborn – Statistical visualization
📈 Dashboard Visualizations

The dashboard includes the following visualizations:

Visualization	Description
KPI Cards	Total Revenue, Total Profit, Orders, Customers
Monthly Revenue	Tracks monthly sales trends
Regional Sales	Compares sales across different regions
Donut Chart	Shows category-wise sales distribution
Heatmap	Displays regional and category performance
Scatter Plot	Analyses the relationship between sales and profit
Histogram	Shows order value distribution


📊 Key Performance Indicators (KPIs)

The dashboard calculates:

Total Revenue: Overall sales generated.
Total Profit: Overall profit earned.
Total Orders: Number of unique orders.
Total Customers: Number of unique customers.
🔍 Business Insights

This project helps answer important business questions:

Which month generates the highest revenue?
Which region contributes the most sales?
Which product category performs best?
What is the relationship between sales and profit?
How are order values distributed?
Which regions and categories have strong sales performance?
