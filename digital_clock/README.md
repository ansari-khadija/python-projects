🌸 Pastel Vintage Digital Clock

A beautiful and simple Digital Clock Application developed using Python and Tkinter. This project features a soft pastel color palette, vintage-inspired typography, and an elegant interface that displays the current time and date.

✨ Features
🕒 Displays the current time in 12-hour format with AM/PM.
📅 Shows the current day, date, month, and year.
🎨 Beautiful pastel color theme with cream, dusty pink, and sage green.
🌷 Vintage-inspired design with elegant fonts and decorative elements.
🔄 Automatically updates the time every second.
🖥️ Simple and user-friendly graphical interface.
📐 Fixed window size for a neat appearance.
🛠️ Technologies Used
Programming Language: Python
GUI Library: Tkinter
Time Module: time.strftime()

⚙️ Requirements
Python 3.x
Tkinter (included with most standard Python installations)

No additional Python packages are required.

🚀 Installation and Usage
Install Python from python.org if it is not already installed.
Download or clone this project.
Open the project folder in VS Code, IDLE, or another Python editor.
Run the following command in the terminal:
python digital_clock.py

The pastel vintage digital clock will open and display the current time and date.

🧠 How It Works
tkinter creates the graphical user interface and its widgets.
strftime() retrieves and formats the current time and date.
Label widgets display the title, time, date, and decorative text.
after(1000, update_clock) schedules the clock to refresh every 1,000 milliseconds.
mainloop() keeps the application running until the window is closed.
🎯 Project Objective

The objective of this project is to learn the basics of Python GUI development, including creating windows, styling widgets, displaying real-time information, and updating labels dynamically.
