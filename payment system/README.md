💳 Payment Management System

A simple desktop application built with Python and Tkinter to simulate payments using different payment methods with an easy-to-use graphical interface.

✨ Features
💰 Enter total and payment amounts
💳 Choose UPI, Credit Card, or Cash
🧮 Calculate remaining balance
✅ Validate payment amounts
🔄 Reset the payment form
🧑‍💻 Demonstrates Object-Oriented Programming and polymorphism
🛠️ Technologies Used
Python
Tkinter & ttk
Object-Oriented Programming (OOP)
🚀 How to Run
Clone the repository:
git clone https://github.com/ansari-khadija/payment-management-system.git

Navigate to the project folder:
cd payment-management-system

Run the application:
python main.py

📌 Note

This is an educational project for demonstrating payment logic and GUI development. No real money is transferred.
