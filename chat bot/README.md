🤖 Friendly Python Chatbot
📌 About the Project

The Friendly Python Chatbot is a beginner-friendly project developed using Python. It interacts with users through text, asks questions, responds to their mood, remembers their name during the conversation, shares jokes, and provides interesting facts.

This project demonstrates the basics of Python programming and interactive user communication.

✨ Features
👋 Personalized Greetings: Welcomes users by name.
😊 Mood Detection: Responds to positive and negative feelings.
🎨 Favorite Color: Asks users about their favorite color.
😂 Random Jokes: Tells a random programming joke.
💡 Fun Facts: Shares interesting facts about Python and computers.
👋 Goodbye Message: Ends the conversation with a friendly farewell.
⏱️ Timed Responses: Uses delays to make conversations feel more natural.
🛠️ Technologies Used
Python 3
time module — Adds delays between chatbot responses.
random module — Selects random jokes and fun facts.

🚀 How to Run
Install Python 3 on your computer.
Clone or download this repository.
Open a terminal in the project folder.
Run the following command:
python chatbot.py

Follow the on-screen prompts and enjoy chatting with the bot!
💻 Example Interaction
🤖 Bot: Hello! Welcome to my chatbot.

How are you feeling today? happy
