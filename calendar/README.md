🌷 Pastel Vintage Calendar

A simple and elegant Calendar Application built with Python and Tkinter, featuring a classy vintage design with soft pastel colors, beautiful typography, and easy month navigation.

✨ Features
📅 Displays the calendar for any month and year.
❮ Navigate to the previous month.
❯ Navigate to the next month.
🌿 Highlights the current date in sage green.
🎨 Beautiful pastel theme with cream, dusty pink, and pale pink.
🌸 Vintage-inspired interface with elegant Georgia fonts.
🖥️ Simple and user-friendly graphical interface.
🔄 Automatically displays the current month when opened.
🛠️ Technologies Used
Language: Python 3
GUI Library: Tkinter
Calendar Module: Python calendar
Date Module: Python datetime

⚙️ Requirements
Python 3.x
Tkinter, usually included with Python
Python standard library modules: calendar and datetime

No additional third-party packages are required.

🚀 How to Run
Install Python from python.org.
Save the Python code as calendar_project.py.
Open a terminal in the project folder.
Run the command:
python calendar_project.py

The vintage pastel calendar window will appear.

🧠 How It Works
tkinter creates the graphical user interface.
calendar.monthcalendar() generates the dates for the selected month.
datetime.date.today() identifies the current date.
Label widgets display the month, weekdays, and dates.
Button widgets allow navigation between months.
show_calendar() redraws the calendar whenever the displayed month changes.
🎯 Project Objective

The objective is to learn Python GUI programming, calendar handling, event-driven button actions, and widget styling while developing a useful desktop application.
