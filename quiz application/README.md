Python Quiz Application
About

A simple command-line quiz application developed using Python. It displays multiple-choice questions, checks answers, and calculates the final score.

Features
Multiple-choice questions
Automatic answer checking
Score calculation
Percentage calculation
Modular code organization
Technologies Used
Python 3
Python functions
Modules and packages
Lists and dictionaries
Conditional statements and loops
Project Structure
main.py — Main program
questions.py — Stores quiz questions
quiz/logic.py — Contains quiz functions
quiz/__init__.py — Initializes the package
How to Run
Install Python 3.
Download or clone this repository.
Open a terminal in the project directory.
Run python main.py.
Learning Objectives

This project demonstrates how to create reusable functions, import modules, organize code into packages, and build a simple interactive application.
