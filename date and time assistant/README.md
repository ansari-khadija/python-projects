📅 Python Date & Time Assistant

A simple, interactive Python application that provides useful date and time utilities through a menu-driven interface. This project demonstrates how Python's built-in modules can be used to work with dates, times, calendars, and countdowns.

✨ Features
🕒 Current Date & Time — Displays the current date, time, and day of the week.
📆 Monthly Calendar — Displays the calendar for any month and year.
⏳ Date Difference Calculator — Calculates the number of days between two dates.
⏱️ Countdown Timer — Counts down from a user-specified number of seconds.
🔄 Interactive Menu — Allows users to perform multiple operations without restarting the program.
✅ Input Validation — Handles invalid dates, incorrect menu choices, and invalid numeric inputs.
📦 Built-in Modules — Uses standard Python modules without requiring external packages.
🛠️ Technologies Used
Language: Python 3
Modules: datetime, calendar, time
Concepts: Functions, loops, conditional statements, exception handling, string formatting, and module imports.
🚀 Getting Started
Prerequisites

Install Python 3 from the official website:

https://www.python.org/downloads/

Installation
Clone the repository:
   git clone https://github.com/ansari-khadija/date-time-assistant.git

Navigate to the project folder:
   cd date-time-assistant

Run the program:
   python main.py


If your system uses python3, run:

   python3 main.py
