🎓 Student Management System

A desktop application built with Python, Tkinter, and SQLite to manage student records through a simple, user-friendly graphical interface.

✨ Features
➕ Add new student records
✏️ Update student details
🗑️ Delete student records
🔍 Search by student ID, name, or course
📋 View all student records
✅ Input validation and duplicate ID prevention
💾 Store records in an SQLite database
🎨 Clean, purple-themed GUI
🛠️ Technologies Used
Python
Tkinter & ttk
SQLite3
🚀 How to Run
Clone this repository:
git clone https://github.com/ansari-khadija/student-management-system.git

Open the project folder:
cd student-management-system

Run the application:
python main.py

🗄️ Database

The application automatically creates a students.db database to store student IDs, names, ages, and courses.


Note: students.db is created automatically when the application runs.
