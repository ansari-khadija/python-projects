🌌 Solar System Simulation Using Python Turtle

An animated Solar System simulation built with Python's built-in Turtle graphics. Watch eight planets orbit the Sun against a beautiful starry background.

✨ Features
☀️ Sun at the Center — A bright yellow Sun.
🪐 Eight Planets — Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, and Neptune.
🌍 Orbit Animation — Planets move around the Sun continuously.
⭐ Starry Background — Randomly generated stars for a space-like atmosphere.
🎨 Colorful Graphics — Different colors and sizes for each planet.
⏯️ Pause and Resume — Press the Spacebar to pause or resume the animation.
🪟 Normal Window Controls — Minimize, maximize, and close the application using the window controls.
⌨️ Keyboard Controls — Press Escape to exit the simulation.
🛠️ Technologies Used
Python 3
Turtle Graphics
Math module
Random module
📋 Requirements
Python 3.x
A desktop environment that supports Tkinter/Turtle graphics

No additional Python packages are required.

🚀 Installation and Usage

1. Clone this repository

bash
git clone https://github.com/ansari-khadija/python-turtle-solar-system.git


2. Navigate to the project directory

bash
cd python-turtle-solar-system


3. Run the program

bash
python solar_system.py


On some systems, use python3 solar_system.py instead.

🎮 Controls
Key	Action
Spacebar	Pause or resume the animation
Esc	Exit the simulation

You can also use the window's minimize and close buttons.
