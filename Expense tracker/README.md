📌 About The Project

Personal Expense Tracker is a beginner-friendly Python project designed to help users record daily expenses, organize spending by category, and calculate total expenditure.

This project was created to practice Python fundamentals through a simple, real-world application.

✨ Features
➕ Add Expenses — Record expenses with a category and amount.
📋 View Expenses — Display all recorded transactions.
💵 Total Spending — Calculate your total expenses.
✅ Input Validation — Handle invalid amounts and user input.
🖥️ Interactive Menu — Navigate through the application easily.

🚀 Getting Started
Prerequisites

Install Python 3 on your computer.

Check your Python installation:

python --version

📥 Installation

Step 1: Clone this repository.

git clone YOUR_REPOSITORY_URL


Step 2: Navigate to the project folder.

cd expense-tracker


Step 3: Run the Python program.

python expense_tracker.py
